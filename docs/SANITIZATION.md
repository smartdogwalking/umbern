# Publication boundaries

This release uses an explicit source-file allowlist and a fresh Git history. It does not publish the private backend or frontend repository in place.

Included: graph-engine source, identity helpers, one deterministic parser, synthetic tests, an offline demo, and explanatory documentation.

Excluded: environment files, keys and tokens, live databases, raw-source caches, contributor records, generated research exports, local machine paths, personal correspondence, infrastructure configuration, and private Git history.

The full private repositories remain private. A future source-worker release requires a separate review of implementation, source reuse restrictions, fixtures, and disclosure risk. No nonprofit-grants worker is claimed or published here: that proposed slice was not present in the backend version used for this release.

No screenshot is included merely because it was available. Images containing browser tabs, personal desktop context, or unreviewed findings are excluded.
